# Student Management System

This is a simple full-stack Student Management System built using React for the frontend and Spring Boot for the backend. The project helps manage student records in an easy and organized way.

## Features

- Add new student details  
- View all students  
- Update student information  
- Delete student records  
- Simple login authentication (basic level)

## Tech Stack

**Frontend:** React, JavaScript, HTML, CSS  
**Backend:** Spring Boot, Java  
**Database:** MySQL  
**API:** REST APIs  

## How it works

- The frontend sends requests to the backend using REST APIs  
- The backend handles all the logic and database operations  
- Data is stored and retrieved from MySQL database  
- Basic authentication is handled using JWT (for learning purpose)

## Project Structure

- frontend/ → React application  
- backend/ → Spring Boot application
